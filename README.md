I design and build full-stack applications — from interactive dashboards and e-learning platforms with real-time video and chat, to social media backends and data analytics with MapReduce.

I work across the stack: React and Next.js on the frontend, NestJS and Express on the backend, PostgreSQL for data persistence, and WebSockets for real-time features. I also work with Java and Python for data processing and tooling.
